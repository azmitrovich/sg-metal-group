# SG Metal Group

Corporate site for SG Metal Group — steel trade and import into the EU (trade, finance, logistics, sustainability).

## Stack

- Vite + React + TypeScript
- i18n: English, Russian, Czech
- Design language adapted from [Own the Patch](https://www.ownthepatch.co.uk/)
- Business positioning aligned with [Moravská Stal](https://moravskastal.cz/)

## Scripts

```bash
npm install
npm run dev
npm run build
```
